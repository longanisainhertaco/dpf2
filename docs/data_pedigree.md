# Data Pedigree

This project bundles small excerpts of reference datasets for demonstration
purposes.  Each dataset is stored under the `data/` directory with accompanying
metadata describing the version and DOI of the original source.

## Available datasets

- **ADAS** – Atomic Data and Modelling for Fusion, version 2022‑01. DOI:
  [10.1063/1.3585817](https://doi.org/10.1063/1.3585817).
- **CHIANTI** – Benchmarking atomic data for the CHIANTI atomic database,
  version 10. DOI: [10.1051/0004-6361/201117592](https://doi.org/10.1051/0004-6361/201117592).
- **LXCat** – Electron scattering cross sections and swarm parameters for
  low temperature plasma modelling, version 2020‑07‑24. DOI:
  [10.1016/j.chemphys.2011.04.020](https://doi.org/10.1016/j.chemphys.2011.04.020).

## Citation requirements

Users of this repository should cite the relevant dataset DOI when publishing
results derived from these data.  The reproducibility manifest automatically
captures the dataset DOI and version so that downstream workflows can generate
proper acknowledgements.
