# Sheath Animation Lab

Use the real-time sheath animation in the web interface to explore how
operating conditions influence plasma motion.

## Steps
1. Launch the simulator and submit a configuration.
2. Adjust the voltage and pressure sliders to vary driver conditions.
3. Observe the evolving sheath in the real-time animation overlay.
4. Press **Share Scene** to export a snapshot for classmates to load.

The animation overlay is available in the browser at
[web/frontend/index.html](../../web/frontend/index.html).
