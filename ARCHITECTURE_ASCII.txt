═══════════════════════════════════════════════════════════════════════════════
                              CRITICAL ISSUES
═══════════════════════════════════════════════════════════════════════════════

🔴 CRITICAL SEVERITY:
1. Authentication Bypass: Token is literally the username (no JWT, no signing)
2. Hardcoded Passwords: "secret" in plain text in source code
3. Results Endpoint: Returns config instead of actual simulation results
4. Missing Auth: Snapshot retrieval has no authentication
5. Insecure Upload: No auth, validation, or size limits

🟡 HIGH SEVERITY:
6. Mock HPC Dispatch: dispatch_to_hpc() just saves config, doesn't run jobs
7. Predictable IDs: Timestamp-based run_id allows enumeration
8. No Rate Limiting: Brute force and DoS attacks possible

🟢 MEDIUM SEVERITY:
9. No Error Handling: File operations can crash the application
10. Race Conditions: WebSocket clients modified during iteration

═══════════════════════════════════════════════════════════════════════════════
                            ARCHITECTURAL NOTES
═══════════════════════════════════════════════════════════════════════════════

❌ NO REAL DATABASE
   - Uses JSON files on filesystem
   - No transactions, no ACID properties
   - No concurrent access protection

❌ NO REAL HPC INTEGRATION
   - dispatch_to_hpc() is a placeholder
   - Mock progress generation
   - No actual simulation execution

❌ NO SESSION MANAGEMENT
   - Users dict in memory (lost on restart)
   - No session storage
   - No logout functionality

❌ NO INPUT VALIDATION
   - File uploads not validated
   - No path traversal checks
   - No size limits
