# CAD Interface

Bindings and adapters for CAD-native geometry ingestion using OpenCASCADE or compatible kernels. The module is intended to:

- Import STEP/IGES geometry directly and convert to simulation-ready boundary representations.
- Generate cut-cell or voxelized meshes for coupling to hybrid-PIC solvers.
- Provide CAD-driven parameterization hooks for automated design sweeps.

Future work will add Python bindings and geometry validation utilities tailored to Dense Plasma Focus chambers and electrodes.
